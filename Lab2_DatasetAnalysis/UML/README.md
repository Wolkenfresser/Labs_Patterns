# UML-диаграммы

В этой папке находятся диаграммы классов и исходные файлы Graphviz DOT. PNG-файлы используются в README и отчёте, DOT-файлы позволяют редактировать диаграммы.

- `abstract_factory.png` — диаграмма паттерна abstract factory; исходник: `abstract_factory.dot`.
- `prototype.png` — диаграмма паттерна prototype; исходник: `prototype.dot`.
